# Master Planner Calendar

Master Planner adds Today, Tomorrow, Week, Month and Year to the main sidebar.
The original Planner and Schedule remain available for comparison.

## Day and Week

Today follows the configured logical start of day. Tomorrow is the next calendar
day relative to it. Week contains seven days, starting on the configured first
weekday. On narrow screens the week stacks vertically.

Day and Week reuse the existing Planner day controls: planned and timed tasks,
repeat projections, calendar events, deadlines, editing and drag-and-drop.
Overdue tasks and deadlines are shown when the range includes Today. Transfers
between visible days use the existing Planner actions.

## Month and Year

Month displays a calendar grid with task counts, up to three task or repeat
projection titles per day, and event counts. Adjacent-month dates are muted.
A task that is both scheduled and has a deadline is counted once per day.

Year displays twelve compact months with indicators for tasks or events.
Select a month title to open Month, or a date to open its Day view. Previous,
current-period and next controls change the displayed range without changing
task data. Today's date is highlighted in both grids.

## Routes

| View                   | Route              |
| ---------------------- | ------------------ |
| Today                  | `/today`           |
| Tomorrow               | `/tomorrow`        |
| Selected day           | `/day/YYYY-MM-DD`  |
| Current week           | `/week`            |
| Week containing a date | `/week/YYYY-MM-DD` |
| Current month          | `/month`           |
| Selected month         | `/month/YYYY/M`    |
| Current year           | `/year`            |
| Selected year          | `/year/YYYY`       |

Calendar screens read the existing Planner and task state. They introduce no new
task engine, storage format, sync entity type or migration.
